# Story Map Together

A zine-style collaborative map tool for layering stories, markers, and hand-drawn annotations onto a neighborhood map — then printing it to share.

## What is this?

Story Map Together lets you upload a screenshot of your neighborhood, then annotate it with story pins, drawn paths, handwritten-style text, and markers in a visual workspace. The result is a personal or community story map meant to be printed and shared — "print and paste everywhere."

## Features

- **Map upload** — Start with a screenshot from any map service
- **Story pins** — Drop markers with short narratives tied to specific places
- **Drawing tools** — Add hand-drawn paths and annotations with a zine aesthetic
- **Text layers** — Write directly on the map in a handwritten style
- **Print-ready output** — Designed to be printed, photocopied, and posted around the neighborhood
